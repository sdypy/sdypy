Contributing Guide
==================

Contributions are welcome and greatly appreciated!

How a change is proposed, checked and merged — the development environment,
the commands, and the spec-driven workflow for non-trivial changes — is
described in one place, for people and AI agents alike:
`AGENTS.md <https://github.com/sdypy/sdypy/blob/main/AGENTS.md>`_.

A :doc:`code of conduct <code_of_conduct>` applies to all spaces managed by the
SDyPy project, including issues and pull requests.
