Contributing to SDyPy
---------------------

Pull requests are welcome. How a change is proposed, checked and merged is
described in one place, for people and AI agents alike:
`AGENTS.md <https://github.com/sdypy/sdypy/blob/main/AGENTS.md>`_.

A code of conduct applies to all spaces managed by the SDyPy project,
including issues and pull requests:
https://github.com/sdypy/sdypy/blob/main/docs/source/dev/code_of_conduct.rst.

Contributed code is licensed under SDyPy's MIT license,
https://github.com/sdypy/sdypy/blob/main/LICENSE. If you did not write the
code yourself, ensure its license is compatible and include the license
information in the contributed files, or obtain permission from the original
author to relicense it.
